# Play Store custom store listings — Hindi, Marathi, Bengali, Telugu, Tamil

Play indexes **each locale's listing separately**. Today Budgetify has one
English listing, so every Hindi-, Marathi-, Bengali-, Telugu- and Tamil-script
query in the category is uncontested by us — even though the app itself has
shipped in all six languages since v1.30. This is the single largest untapped
surface in the whole plan, and the competition in these locales is a fraction of
what it is in English.

Add them in **Play Console → Grow → Store presence → Custom store listings**
(or the language selector on the main store listing), one locale at a time.

> **Terminology is taken from the app's own translation table**
> (`lib/l10n/app_strings.dart`), so the listing and the UI use the same words —
> खर्च / बजट, खर्च / बजेट, খরচ / বাজেট, ఖర్చు / బడ్జెట్, செலவு / பட்ஜெட்.
>
> **Have a native speaker read each block before publishing.** The vocabulary is
> grounded in shipped, reviewed strings, but full marketing prose is a different
> register from UI labels, and store copy is not something to ship unread.
